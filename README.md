# Projeto Inicial

Este repositório foi criado com o objetivo de praticar a clonagem de repositórios do GitHub e explorar ferramentas essenciais no desenvolvimento web, como VS Code, Markdown e Git.

## 📁 Estrutura do Projeto

- **index.html**: Página principal do projeto.
- **css/**: Contém os arquivos de estilo (CSS) utilizados no projeto.
- **img/**: Armazena as imagens utilizadas nas páginas.
- **paginas/**: Diretório destinado a páginas adicionais do projeto.

## 🛠️ Ferramentas Utilizadas

- [Visual Studio Code](https://code.visualstudio.com/): Editor de código-fonte.
- [Markdown](https://www.markdownguide.org/): Linguagem de marcação para formatação de texto.
- [Git](https://git-scm.com/): Sistema de controle de versões distribuído.
- [GitHub](https://github.com/): Plataforma de hospedagem de código-fonte.

## 🚀 Como Executar o Projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/Julio-CRodrigues/projeto-inicial.git
   ```

2. Navegue até o diretório do projeto:
   ```bash
   cd projeto-inicial
   ```

3. Abra o arquivo `index.html` em seu navegador preferido ou utilize o VS Code para visualizar e editar o projeto.

## 📌 Observações

Este projeto é uma iniciativa de aprendizado e prática, focado em entender a estrutura básica de um projeto web e o uso de ferramentas fundamentais no desenvolvimento.
